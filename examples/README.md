# Examples

Example AIVane automations (Applications) will live here: one directory per automation, with a short README describing the task, its inputs and outputs, and how to import and run it. None are published yet.

The directory also holds helpers for the Android phone control beta (see [docs/android/README.md](../docs/android/README.md)):

- [`smoke-flow.md`](smoke-flow.md): smoke flow for a fresh Android REPL beta installation
- [`start-app-repl.sh`](start-app-repl.sh) / [`start-app-repl.ps1`](start-app-repl.ps1): start the Android REPL service over ADB, optionally installing an APK; usage is in [docs/install-agent-android.md](../docs/install-agent-android.md)
